# GoalFlow

Менеджер задач с целями, проектами и учётом времени: видно, к какой цели ведёт задача и сколько времени на неё ушло. Данные хранятся в браузере пользователя.

> Проект в разработке. Ход работы — в [плане](docs/plan.md).

## Возможности

- **Цели, проекты, задачи.** Задача лежит в проекте, прямо в цели или в «Неразобранных». Отдельный список «Все» показывает все задачи сразу. Задачи стоят в порядке создания, выполненные скрыты и показываются по ссылке внизу списка. Прогресс цели и проекта считается по весу задач в story points (SP).
- **Поля задачи.** Описание, оценка в SP, дедлайн (просроченные подсвечиваются), приоритет, свободные теги (до 5 у задачи) с автокомплитом из справочника (новые теги запоминаются в нём сами), связанные задачи с переходом между ними. В карточке задачи поля спрятаны за панелью иконок, заполненные видны плашками.
- **Фильтры и подборки.** На экране «Все» задачи отбираются по статусу, приоритету, тегам, дедлайну (в каждом условии можно отметить несколько значений), «без цели» и «больше 4 ч». Готовые подборки («Без цели», «Застряли», «Дедлайн на этой неделе», «Просроченные») и свои сохранённые сочетания условий — рядом над фильтрами. Просроченные задачи отмечены значком и красной датой.
- **Календарь.** Месяц с числом задач по дням и список задач выбранного дня; задачу можно перетащить за ручку на другой день — дедлайн изменится.
- **Доска.** Колонки по статусам; задачу можно перетащить в другую колонку — статус изменится. Наверху колонки — важное и срочное, в «Готово» — выполненное за неделю. Фильтры и подборки действуют и на доску, карточка задачи открывается в окне поверх доски.
- **Быстрый ввод.** Задача с полями создаётся одной строкой: `Купить домен #работа !1 @Запустить продукт ^пт 3sp` — тег, приоритет, цель или проект, дедлайн и оценка; после значков выпадают подсказки, до создания видно, что распознано. Работает в поле «Новая задача» на экранах и в окне по Shift+N.
- **Горячие клавиши и палитра команд.** Ctrl+K (или Shift+K) — палитра: найти задачу, перейти в пространство, выполнить действие. Shift+N — новая задача, Shift+X — выполнена, Shift+S — таймер, Shift+V — список / календарь / доска, «?» — шпаргалка по клавишам.
- **Учёт времени прямо в задаче.** Таймер в строке задачи и ручной ввод; время видно у задач, проектов и целей, а на экране «Затраты времени» — итоги за сегодня и за неделю, месяц (в том числе прошлые) или свой период «с … по …». Оттуда же записи времени выгружаются в CSV для Excel — за выбранный период или за всё время.
- **Напоминание о забытом таймере.** Через час работы таймера появляется плашка со звуковым сигналом и значок 🔔 в заголовке вкладки. Сигнал повторяется каждые 5 минут, пока нет ответа; его можно выключить. Браузеры разрешают звук только после действия на странице, поэтому после перезагрузки сигнал прозвучит при первом клике.
- **Резервная копия.** Экспорт всех данных в JSON и восстановление из него. Если восстановили не тот файл, прежние данные можно скачать или вернуть одной кнопкой. Копии данных до восстановления и повреждённых данных временно лежат в «Хранилище копий» — их можно скачать, вернуть или удалить.
- **Светлая и тёмная тема.**

## Технологии и почему

- **Next.js 16 (App Router) + TypeScript**
- **Tailwind CSS 4** — стили
- **zod** — проверка данных
- **lucide-react** — иконки
- **@dnd-kit** — перетаскивание в календаре и на доске
- **localStorage** — хранение данных в браузере

Почему выбраны именно они — в [журнале решений](docs/decisions-log.md).

## Запуск локально

Нужен Node.js 20.19+, 22.13+ или 24+ (сам Next.js работает и на 20.9+, но часть инструментов линтера требует более новой версии).

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу http://localhost:3002 (порт 3002, а не стандартный 3000 — чтобы не конфликтовать с другими проектами).

Другие команды:

- `npm run build` — сборка для продакшена;
- `npm run lint` — проверка кода линтером;
- `npm run typecheck` — проверка типов TypeScript.

## Структура

- `app/` — страница и общий макет (App Router);
- `components/` — интерфейс: боковая панель, экраны, задачи, таймер;
- `lib/` — модель данных, хранилище в localStorage, расчёт прогресса и времени, резервная копия;
- `docs/` — план разработки и журнал решений.
