# План разработки

Статусы: ⬜ не начато · 🔄 в работе · ✅ готово · ➡️ перенесено в планы развития. ⚑ — точка решения владельца проекта (варианты и выбор — в [журнале решений](decisions-log.md)).

## ✅ Итерация 4. Быстрые действия

- [x] ⚑ Клавиши — Shift+буква, Ctrl+K / Shift+K — палитра, «?» — шпаргалка (+ кнопка и пункт в палитре)
- [x] ⚑ Быстрый ввод — метки `#` `!` `@` `^` `sp` с автокомплитом; несуществующая цель или проект не создаются
- [x] ⚑ Быстрый ввод по Shift+N и в полях «Новая задача»; сообщение «добавлена в …» со ссылками
- [x] ⚑ Палитра: задачи, пространства, действия
- [x] Разбор быстрого ввода и поле с автокомплитом и предпросмотром
- [x] Палитра команд, шпаргалка по клавишам
- [x] Горячие клавиши, переход по задачам стрелками, обводка фокуса, сообщения с «Отменить»
- [x] Значок просроченной задачи, мультивыбор в фильтрах, подборки над фильтрами (уточнения владельца)
- [x] ⚑ Доска по статусам — третий вид на «Все»: фильтры действуют, в «Готово» — выполненные за 7 дней, порядок — по приоритету и дедлайну, доска на всю ширину
- [x] Доска: перетаскивание карточки меняет статус (как смена статуса в карточке)
- [x] ⚑ Карточка задачи в окне поверх экрана — на доске и из сообщения «добавлена в …»
- [x] ⚑ Сообщения внизу исчезают сами на втором действии; после окна Shift+N сообщение «добавлена в …» всегда

**Результат:** основные действия выполняются с клавиатуры.
